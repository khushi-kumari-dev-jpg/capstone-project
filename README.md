# Healthcare-appointment-attendance-analysis
Healthcare Appointment Attendance Analysis

Project Overview

This project focuses on analysing healthcare appointment data to understand patient attendance behaviour and identify factors associated with missed appointments.

The analysis examines how different factors, such as age, gender, SMS reminders, and waiting time, are associated with appointment attendance.

Objectives

- Analyse overall healthcare appointment attendance.
- Calculate attended and missed appointments.
- Examine gender-wise attendance patterns.
- Analyse the relationship between SMS reminders and attendance.
- Study attendance patterns across different age groups.
- Understand the association between waiting time and missed appointments.
- Present findings through data visualizations.

Dataset Description

The dataset contains 106,987 healthcare appointment records.

Important attributes include:

- Patient ID
- Appointment ID
- Gender
- Scheduled Day
- Appointment Day
- Age
- Neighbourhood
- SMS Received
- Showed_up (Attendance Status)
- Date Difference

Business Questions

1. What percentage of patients attend their scheduled healthcare appointments?
2. Is there an association between SMS reminders and appointment attendance?
3. Does waiting time have an association with missed appointments?

Conclusion

The analysis shows that approximately 79.7% of appointments were attended, while 20.3% were missed.

Patients who missed appointments had a higher average waiting time. The analysis also identified differences in attendance patterns based on age, gender, and SMS reminders.

This project demonstrates how Data Science and data visualization can help identify patterns in healthcare data and support better appointment management.
